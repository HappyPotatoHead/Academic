#### Question III
I will first load a MySQL driver. Then, I would create the connection with the loaded driver to the MySQL database. To execute any SQL statements, I first have to create a statement with `Statement st = new Statement();`. To query a database, the `.executeQuery()` method is used and the returned result is stored in a `ResultSet` object. The SQL statement would be `SELECT employeeID, name FROM EMPLOYEES;`. The full code is: `ResultSet rs = st.executeQuery("SELECT employeeID, name FROM EMPLOYEES")`. To display the result in the same manner as the database, I would retrieve the metadata with `getMetaData` and store the result in `ResultSetMetaData`. The code is `ResultSetMetaData rsMD = rs.getMetaData()`. To display the table, I would use `for` and `while` loop. The full code:
```run-java
Statement st = conn.createStatement();
ResultSet rs = st.executeQuery("SELECT employeeID, name FROM Employees");
if (rs != null){
	ResultSetMetaData rsMD = rs.getMetaData();
	final int columnNo = rsMD.getColumnCount();
	for(int index = 1; index <= columnNo; index++)
		System.out.println("%s\t", rsMD.getColumnName(index));
	while(rs.next()){
		for(int index = 1; index <= columnNo; index++){
			System.out.println("%s\t%n", rs.getString(index)); //getObject(index) is fine too
	}
}
```
