### Question C
**Inline**
The CSS style sheet is written in the `html` tags themselves. The CSS is applied with the style attribute where the CSS styling is enclosed in double quotation. If multiple CSS styling are used, a ; is needed. Because of this nature, the styling has to be applied to each tag individually.
```html
<p style = "color: blue;padding: 10px;">This text is blue!</p>
```

**Internal/Embedded**
The CSS style is written in the `html` file but not directly in the `html` tags. Wrapped in `<style>` and `</style>` tag instead. 
```html
<style>
	p{
		color: rgba(0,0, 255);
	}
</style>
<p>This text is blue!</p>
```

**External**
The CSS style is written in a separate `.css` file and linked to the `html` via the `link` tag. Inside the html file,
```html
<link rel = "stylesheet" href = "style.css"/>
```
In the CSS file,
```css
p{
	color: rgba(0,0, 255,0.5);
}
```

#### Question II
Single-line comments can be added to the JavaScript code with `\\` while multiline comments can be added with `\**\`. Any text that follows the `\\` in the same line is ignored while any text inside `\**\` is ignored.

Single-line comments is used when the message is short and can be contained in one line without much horizontal scrolling. For example
```js
// poison damage is 5 hitpoints per second
let poison = 5;
```

Multiline comments are used for longer messages such as explaining what the program does or detailing the flow of a function. 
```js
/* 
This is a Book management system. This progam can: 
1. Add book
2. Remove book
3. Update book
4. Read book
*/
```
Never write comments while assuming prior knowledge; always write them without any assumption.

When adding comments, it is important to add meaningful information rather than writing down something that is obvious. For example,
```js
/*
The player has 5 hitpoints because:
	the player is playing as a child,
	the player is a weak entity
*/
let hp = 5;
```
is better rather than
```js
// hp is set to  5
let hp = 5;
```

The expiration date of a cookie can be configured by using `expires=`. The date is written in GMTString format. If no expiration date is configured, the cookie will disappear when the user exists the browser.
```js
let date = new Date();
// Expiration date is configured to 24 hours after the current date
date.setTime(date.getTime() + 24* 60* 60* 1000);
document.cookie = `expires=${date.toUTCString()}`;
```

```js
let date = new Date();
```
