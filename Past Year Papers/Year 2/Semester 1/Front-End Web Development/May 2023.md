### Question B
Block-level elements are elements that start the content at a new line while inline-level elements are elements that start its content in the same line as it is placed. In a block-level element, the horizontal length spans across the width of the element's parent container but in inline-level element, the horizontal length is set to only fit the content of the tag. Block elements have built in vertical length but inline elements do not.
Examples of block-level elements are `<p></p>` and inline-level elements are `<span></span>`.

Select child elements at even numbering to apply styling to
```css
li:nth-child(even){
```

Select child elements at odd numbering to apply styling to
```css
li:nth-child(odd){
```

```css
li:first-of-type{
```

## Question 4
### Question A
The three mechanisms are **cookies**, **session storage**, and **local storage**. 
All of these three mechanisms have the same limited storage issue so they cannot be used to store extensive data or complex database; however, cookies have the least storage - 4KB - compared to the two with both having around 5MB to 10MB, making these two to be more suitable to store larger amount of data.

In cookies, expiration date can be set, if not, the data stored will be gone when the user exits the browser, but in session storage, the data stored will disappear once the user exits the browsing session or closes out of the tab and no data will be retrieved when the user revisits the website in; however, in local storage, the data stored will persist across multiple browsing sessions, unless explicitly removed. When the user logs in in separate session, data will be retrieved from the client's computer. 

The three mechanisms store value in the same way, via key-value pair. 

Cookies can be used for user preferences, session storage can be used for multistep form submission, and local storage can also be used for user preferences.

### Question C
Caption can be incorporated into a video via the `track` tag. The default attribute is used to indicate the default caption. If the default caption is unavailable, and if multiple captions are added, the first one will be tried first. If the first caption does not exist or isn't supported, the second one will be used.
```html
<track label ="Chinese"
	   kind = "captions"
	   srclang ="cn"
	   src = "chinese.vtt" default/>
<track label ="English"
	   kind = "captions"
	   srclang ="en"
	   src = "english.vtt"/>
```
