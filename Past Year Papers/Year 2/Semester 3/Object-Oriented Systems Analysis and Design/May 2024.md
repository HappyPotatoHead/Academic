Functional requirements refers to the behaviours of the system while non-functional requirements refers to the desirable characteristics of the system. The functional requirements gathered are what users can do with the system and how they can do it. Non-functional requirements are performance level, security, cultural and political requirements, and operational requirements. For example, in an e-commerce setting, a functional requirement would be, "the user should be able to add items to their carts" while non-functional requirement would be "the page should load within 2 seconds".

### Question C

In server-based architecture, the server is the side that handles of the software components: data storage, data access logic, presentation logic and application logic, and the client side just inserts data. In client-server architecture, the client is the one who handles application logic and presentation logic while the server handles data storage and data access logic.

Security:
1. Server-based architecture
	- The server contains all of the software components, while the clients only provide inputs. This makes the need to strengthen security revolving the servers only. However, this makes the server into a single point of failure, where if the server is compromised or breached, the whole system would be affected. 
2. Client-server architecture
	- Client handles presentation and application logic while server handles data access logic and data storage. This architecture introduces more complexity to the security where there are more client-side attacks or vulnerability since application logic resides on the client side. 

Ease of development:
1. Server-based architecture
	- Server-based architecture is more difficult to development and it is also costly. Durable and high quality infrastructure has to be developed and maintain all of the software components: data storage, data access logic, presentation logic, and application logic.
2. Client-server architecture
	- This is easier to develop since there is lesser load on the server side as it would only be responsible to store data and manage data retrieval. Half of the load is on the client side, who will handle application logic and presentation logic. 
	- So, some of the infrastructure needed for server-based architecture may not be necessary in client-server architecture.

### Question C

Normalisation concept refers to creating a set of relations that possess desirable properties. In normalisation, there are anomalies that are removed: update, insert, and delete anomalies. Additionally, normalisation undergoes several forms; unnormalised form, first normal form, second normal form, and third normal form. If needed, normalisation can be extended to N-formal form. In first normal form, repeating groups are removed and each field is ensured to only have one field, atomic. In second normal form, partial functional dependency is removed. In third normal form, transitive functional dependency is removed.
