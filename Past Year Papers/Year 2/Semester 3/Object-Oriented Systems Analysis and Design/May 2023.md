### Question D

The major difference between phased development and throwaway prototyping lies in how the complete system is created. In phased development, the system is divided into several versions with the first version bundled with the core features. The subsequent versions are built on top on the first version with users' feedbacks until a complete system is created. In throwaway development, design prototype will be created to help resolve issues or ambiguity in the user requirements. Once the user requirements have been resolved, the design prototype is discarded and the real system can be developed.

Attribute refers to the characteristics and properties of the entity while aggregation and composition are a subset of association relationships between entities. For example, a `Human` entity can have attribute name, age, and gender. Aggregation is a weak form of association while composition is a stronger form of association. This can be seen with the lifespan dependency in aggregation and composition. In aggregation, the part and the whole can exist separately and have separate lifespan while in composition, the part and the whole cannot exist separately and the part's lifespan is dependent on the whole.

### Question C

*In SEP, they are presentation, business, persistence, and database*


In server-based architecture, the server will handle all of the software components - data storage, data access logic, presentation logic, and application logic, while in client-server architecture, the load is shared between client and server - client handles presentation logic and application logic while server handles data storage and data access logic. In server-based architecture, the client will only be giving input for the server to process, while in client-server architecture, the client will be handling both processing data and requesting data, and the server will handle the database and processing queries. This means that in server-based, the client-side does not require much hardware while the server requires powerful hardware, while in client-server, the cost is divided between client and server.
