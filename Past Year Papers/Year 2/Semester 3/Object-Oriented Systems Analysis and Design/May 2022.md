### Question B

Functional model describes what the system gives the user, while behavioural model describes how the system react to user interaction or events. Functional models are depicted with use case diagrams while behavioural models are depicted with activity diagram, sequence diagram, or behaviour state machine. Functional model focuses showing what the relationship is between the user and the use cases. Behavioural illustrate the dynamic aspect of the system such as the flow of information, passing of messages, and change in state of objects.

### Question C

Both generalisation and specialisation are methods meant to implement inheritance in the system. Generalisation is a bottom-up approach to implementing inheritance. In generalisation, a generic supertype or entity is created from a set of specific subtypes. The generalisation is done via comparing the methods and attributes across the subtypes to determine which ones are repeated multiple times. This is commonly used to simplify the design of the system. For example, `Progammer`, `Janitor`, and `Clerk` can be grouped into `Employee`. 

Specialisation is a top-down approach to implementing inheritance. In specialisation, a set of specific subtypes are created from a generic super type. For example, `Student` specialising to `Undergraduate` and `Postgraduate`. This is usually done to specify certain components of the system for certain features or requirements.

Two-tier architecture involves client and server while three-tier architecture involves client, application server and database server. In two-tier architecture, the client will handle presentation logic and application logic, while the server will handle data storage and data access logic. In three-tier architecture, the client will handle presentation logic and provide the input and data needed to the application server for the application server to process it. The database server will handle data storage and data access logic.
