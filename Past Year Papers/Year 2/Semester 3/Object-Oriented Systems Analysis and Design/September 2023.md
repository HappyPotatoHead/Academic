### Question C

In phased development, the information system is divided into several version, with each version more complete than the next while throwaway prototyping focuses on designing design prototypes to resolve issues and ambiguity regarding system requirements. 

In phased development, the first version contains the most crucial features and functions for the user to test, while in throwaway prototyping, design prototypes are created and redesigned repeated based on user feedback and until the issue has been resolved. 

In phased development, the analysis, design, and implementation is done repeatedly until a complete version is created, while in throwaway prototyping, analysis, design, and implementation is only done repeated until the issue has been completed.

### Question B

Encapsulation refers to the bundling of attributes and methods into a single class to represent a single unit, while information hiding refers to hiding the implementation of the functions or class. In encapsulation, this is achieved by enforcing visibility such as private and public, while in information hiding is achieved with abstract classes. 

Additionally, encapsulation controls access to certain attributes and methods of a class from another class, while information hiding allows the users to use the methods without needing to know how it was implemented.

### Question A

Aesthetics refers to designing the user interface to be visually appealing and easy to read, while consistency refers to <mark style="background: #FF5582A6;">keeping the navigation and functions of buttons and icons the same in multiple pages of the user interface</mark> *ensuring that the functions of buttons and icons remain the same across multiple user interfaces* and minimal user effort refers to allowing user to navigate the system or interact with the system with as little effort as possible. 

In aesthetics, the designer can focus on using colours that pair well together while allowing the texts to be readable. In consistency, the user should be able to predict what is going to happen, allowing them to only learn one portion and apply them to other. Finally, in minimal user efforts, the general rule is the three-click rule, where user should only have 3 clicks to navigate to any place in the system.
