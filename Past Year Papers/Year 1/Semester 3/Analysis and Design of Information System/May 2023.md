#### Question I
Corrective maintenance refers to changes made to the system to correct design flaws, coding flaws and implementation flaws. Corrective maintenance makes up majority of the types of maintenance done onto a system. Most corrective maintenance happen immediately after the system has been installed. When corrective maintenance is done, no actual value or additional features are added to the system  
Preventive maintenance refers to the changes made to the system to prevent any possible future issues. For instance, generalise the format at which information is sent from a system to a printer so that the system can adapt to evolving printer technology.
