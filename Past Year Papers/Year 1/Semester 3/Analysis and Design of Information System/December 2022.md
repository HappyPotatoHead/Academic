### Question A
1. Stress Testing
	1. Try to break the system to see what happens
	2. For instance, have a lot of users login to the system at the same time to see what happens and what is the maximum number of users that the server can handle at once. 
2. Performance testing
	1. Running the in various environment to see how it runs
	2. Running the system in different operating system
	3. Running the system in devices that have different specifications
3. Security testing
	1. Test if the system can defend against improper penetration. 
	2. Test if the system can protect user data from unauthorised changes
	3. Test if the firewall is working properly and can defend against various forms of attack such as DOS attacks, and SQL injection
