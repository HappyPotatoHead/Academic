## Question 3
### Question A
#### Question I
preventive system maintenance is the changes made to the system to prevent technology related problems from arising in the future but adaptive system maintenance refers to the changes made to the system to adapt with changing business needs and technology. Preventive system maintenance is usually done at a regular interval or when there is a sign of deterioration but adaptive maintenance is usually done when an issue such as changing technology or updates has arrived that demands change. Preventive system maintenance involves regular check ups, updating documentation, or refactoring code to improve efficiency but adaptive system maintenance involves adding or modifying a function in the system extensively. Preventive system maintenance ensures the system can keep running smoothly without internal obstruction whereas adaptive system maintenance ensures the system can run smoothly despite technological changes
#### Question III
I will perform perfective maintenance. Perfective maintenance focuses on making changes to the system that improves the performance of existing system. Corrective maintenance focus on fixing issues that arise. Improving the response time to react faster to customer's requests is considered perfective maintenance as it improves performance. However, if the slow response time is due to a bug in the system, the maintenance done on the system will be considered as corrective maintenance.
