#### Question I
**Base case:** $n<=1$
**Recursive case**: 
```cpp 
return Func(n-1)+Func(n-2);
```
If the number is less than 1 or equals to 1, return the number. If that's not the case, call the function with n subtracted by 1 and function with n subtracted by 2. Return the added returned value.
