1. Structural hazard
	1. This happens when the resource has to be used in two different ways at the same time
	2. two instructions try to read the same memory at the same teim
2. Data hazard
	1. The value of a register has not yet been written in the register file when it is being used in the next instruction
		- add \$s0, \$t0, \$0
		- subi \$s1, \$s0, 100
3. Control hazard
	1. The next instruction begins even before it has been decided
		- bne \$s0, \$s1, loop
		- addi \$s2, \$0, 100

## Question 5
### (a)
![[Translating HLL to LLL]]
**Compiler**
Compiler converts each higher level language file into assembly files that contain assembly language
**Assembler**
Assembler converts the assembly files into object files containing machine language. The Assembler follow these steps
1. Reads and uses assembler directives
	- .text 
	- .data
	- .global sym
2. It replaces pseudoinstructions
3. Assigns instruction address
4. Places addresses of symbols in the symbol table
5. Lists items that needs address that has not been known yet in the reallocation table
The translation has two passes
*First pass*
1. Reads each line of an assembly file
2. If the line starts with a label, it records the name of the label and the address of the memory that the instruction occupies
*Second pass*
1. Translate into machine code using the symbol table
**Linker**
Links all the object files along with the included libraries to produce a single .exe file and resolves absolute addresses. The linker will merge text and data segments. It will search for references in the symbol table. If not found, it will search for them in a library. Finds the absolute memory addresses and fill them in the machine code
**Loader**
The loader will execute the program. 
The operating system will follow these steps to execute the program
1. Read the executable file to determine the text size and the data size
2. Create new address space for the program
3. Copy the instruction and data into the new address space
4. Copy the arguments passed into the program into the stack
5. Initialise machine registers
	1. Most registers are cleared
	2. \$sp -> stack pointer
	3. \$gp -> global pointer
6. Jump to beginning of program (at the start of text segment)

**Instruction Fetch**
The processor fetches the instructions from the memory
**Instruction Decode**
The control unit decodes the instructions (Instruction formats, operands, instruction itself) to produce the control signals to determine the operations to be done by the memory. 
**Instruction Execution**
The datapath executes the instructions according to the control signal
**Write Back**
The output is written back into memory
**Next instruction**
Processor fetches the next instructions from the memory
