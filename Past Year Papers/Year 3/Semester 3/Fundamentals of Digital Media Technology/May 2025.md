### Question A -> when it doubt give an example. 

**Advantages**

1. Improve information retention
    - A multimedia presentation often engages more than one senses. For example, sight and hearing are often engaged simultaneously.
    - This improves the retention of information as the brain has more neural pathways to retrieve the data. When auditory and visual stimuli are paired, the brain encodes the information through dual coding, making it easier to recall than if it had been presented through a single medium.
2. Eases understanding of information
    - A multimedia presentation presents the concepts with more than one medium.
    - For example, physics concept such as the doppler effect can be made easier to understand with the use of both animation and sound. To illustrate, an animation of a car can be used; as the car gets into frame, the sound gets louder, and as the car exits the frame, the sound gets softer.
3. Makes content more engaging
    - By varying the type of stimuli, the presenter can reset the audience's attention span.
    - For example, shifting from a static slide to a short video clip
    - To illustrate, when presenting about global warming, instead of only showing statistics, the presenter can use a time-lapse visualisation of melting glacier. This visual sotrytelling captures interests more effectively than raw data. This also creates a narrative flow that keeps the audience engaged, curious of the next information

**Disadvantage**

It can be time consuming. Creating a multimedia presentation that incorporate audio, video, animation, and interactivity takes a lot of effort and time that busy lecturers and teachers may find difficult to make time for. Additionally, ensuring the flow between the various multimedia element remain simple yet easy to follow can increase the complexity of the process.

### Question A -> say the same thing as for images

1. Uses less storage size
    - Vector graphic fonts are represented mathematically instead of by sequences of bits, the file size for vector graphic fonts is smaller compared to bitmapped font.
    - Because vector graphic fonts are represented mathematically, various fonts share the same components. This in turn, leads to a reusable component design, keeping things simple and consistent; similar fonts will share similar components, and additional components are added only when needed.
    - However, for bitmapped fonts, each font have their own sequences of bits.
2. Scalable 
    - Vector graphic fonts maintain their quality when scaled to be larger compared to bitmapped fonts where their quality diminishes as the screen is scaled to be larger.
    - This allows vector graphic fonts to be more flexible and applicable to various screen sizes compared to bitmapped fonts.
    - Designers and developers can confidently implement their projects using vector graphic fonts on a screen size without worrying about the quality when the project is viewed on different screen resolution.
3. Faster transmission and smaller bandwidth
    - This, in turn can speed up transmission of the font, especially when downloading the font, since there the file size is smaller.
    - Additionally, its smaller file size also uses lower bandwidth.

### Question A

1. MIDI is device-dependent
    - Unlike, digital audio, the sound of MIDI is dependent on the hardware or software receiving it; it will not sound exactly the same, unless the same hardware and software are used. 
    - Digital audio, however, can be played on various devices and sound similar
2. MIDI requires knowledge on music theory
    - Creating a MIDI file requires the operation of synthesiser to create instructions, which requires music theory knowledge to operate.
    - Digital audio can be recorded with only a click of a button and a microphone.
3. Smaller file size
    - MIDI file size is smaller than digital audio
    - This is because MIDI does not contain actual sound recording, instead it contains instructions that instruct the device (desktop computer or synthesiser) on how to play the audio
4. MIDI is easier to edit compared to digital audio
    - This is due to the design of MIDI, instructions, instead of sound recording. This means that changes can be made easily after recording without losing quality.
    - Digital audio is more difficult to be edited, especially related to the pitch and amplitude of the audio.

## Question 5

### Question A

1. VR does not involve projecting an image of the user onto a display while second person VR does. 
    - VR generally involve first person perspective, whereby the user does not see a body of the character, or third person perspective, whereby the user sees the model of a virtual avatar that they are controlling.
    - Second person VR captures the image of the user can projects them onto the screen, so the user is seeing themself interacting with the virtual world.
2. VR is easier to implement than Second Person VR
    - Second person VR involves complex implementation of cameras. 
    - It is difficult to keep track of every movement of the user while ensuring real-time feedback as the user interacts with the virtual world.
    - VR is easier to implement as it mainly generates and displays a virtual environment, without needing to project an image of the user onto the screen. 

### Question B

1. Requires high processing power
    - The real-time projection and coordination to keep track of the user requires constant real-time by the hardware.
    - Additionally, the hardware should also be able to render complex 3D model and make changes constantly according to the users' interactivity. 
2. More difficult to create an immersive experience
    - The latency between user interaction and the effects on the virtual environment, makes it difficult for the user to be fully immersed. 
    - This latency keeps user highly aware of their real-world physical surroundings, as their brains will immediately identify this disconnect.
3. High implementation complexity
    - Unlike other forms of VR, second person VR has to keep track of the movement of the user's physical body, without the use of any input devices such as a handheld device or a wand. 
    - The lack of such input devices forces developers to rely on depth sensing cameras to track skeletal joints. This is prone to occlusions, where if one body part hides another, it creates a glitch.
    - Without buttons, developers have to develop a system that can differentiate intentional commands from casual movements

### Question C

1. VR does not involve the interaction between a virtual world and a real-world environment, while MR allows the interaction of virtual objects with real-world elements.
    - In VR, the users are controlling a virtual character, be it first person or third person, to interact with only virtual objects.
    - However in MR, virtual elements are allowed to interact with real world elements; for example, a virtual ball bouncing as it hits the floor.
2. VR is completely immersive, while MR is only partially immersive
    - This is because VR completely surrounds the user with the virtual world, blocking out any physical world elements.
    - MR integrates the real-world as part of the experience. This means that the user can still see their surroundings.
