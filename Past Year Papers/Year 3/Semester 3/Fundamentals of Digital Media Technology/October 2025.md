### Question D

1. Consistent Design
	- Different pages should have similar designs. For example, the colours of various pages of the same application should remain. 
	- Additionally, the navigation buttons of the applications should also remain the same.
2. Design Familiarity
	- The icons used in the application should be familiar to the user that the user can guess what the icons do without needing to look it up. 
	- For example, the icon used to redirect the user to the homepage of the application should be a home icon. This allows the user implicitly determine that the icon brings him back to the homepage.  
3. Ease of Interactivity
	- The placement of the buttons to navigation to various pages of the navigation should be at convenient places. Ideally, if on a handheld device, near the areas where fingers and thumbs are most commonly located.
	- Additionally, navigation should also follow the 3-click rule. The user should only click at most 3 times before reaching the desired destination
4. Feedback
	- The application should provide an immediate response for every user action. For example, changing colour when clicking a button or a notification sound on the completion of a progress or action. 
	- The application should also notify the user immediately if the action is not permitted or there exist in error.

### Question D

1. Level of Presence
	- Immersive VR allows the user to be completely immersed in the virtual world by covering every aspect of the real world
	- Non-immersive VR displays the virtual environment via a desktop or a phone.
		- Users still have high level of awareness of what is happening in the real world
2. Hardware and Display
	- The hardware used for immersive VR typically involve headset, sensors, trackers, and cameras, alongside computers 
	- The hardware involved in non-immersive VR tend to only involve a display such as a monitor or a phone and a processing unit 
3. Interaction and Tracking Methods
	- Immersive VR uses sensors and trackers to track the movement of the user as they interact with the virtual world, allowing a more direct interaction
	- Non-immersive VR typically involves keyboard and mouse or other external input devices to allow an indirect interaction.
4. Use Cases and Accessibility
	- Immersive VR is generally used to train individuals to perform high-stakes, important tasks such as surgeries or piloting. It can also be used to entertainment, but the required devices are generally more expensive
	- Non-immersive VR is generally cheaper as it requires much lesser hardware and software to execute, making it more ideal for most people.
