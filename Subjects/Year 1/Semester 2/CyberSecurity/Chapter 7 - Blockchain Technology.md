# Block Chain
## What is blockchain
It is a growing list of records that are connected through encrypted links. Blockchain are used to keep records of transactions such as bitcoin transaction. The blocks in blockchain are hard to be modified as it would require any subsequent blocks to be changed as well. 

| Advantages                                      | Disadvantages           |
| ----------------------------------------------- | ----------------------- |
| Secure                                          | High energy consumption |
| Data is immutable -> changes made are permanent, so 0 percent of fraud | It is very complex      |
| Greater transparency -> Decentralised ledger    | Scalabitilty             |
|                                                 |             Lack of governmence            |
## Hash/Message Digest in Block chain
All data along with the encrypted digital signature is sent over the network for verification. *Definition of hash function, see* [[Chapter 1 - Information Security Basics#Hash function|Hash function]]. The data is a combination of sender's bitcoin address and the bitcoin amount to be transacted. The hash value is then encrypted by the private key to produce digital signature. The data is compiled into a block and verified before being added to the block chain
## Network protocols
### Peer - to - peer protocol
Blockchain network uses P2P protocol and establishes a direct connection between nodes
### Transaction protocol
Blockchain system uses transaction protocol to govern how transactions are created, signed, validated and propagated. 
### Privacy protocol
Blockchain system uses this protocol to ensure that participants can make transaction without having specific details being revealed publicly. 
### Block propagation protocol
Blockchain system uses block propagation protocol to define how new blocks should be distributed among the nodes. It also ensures, each node gets the latest validated blocks
## Distributed Ledger
Distributed ledger is a decentralised database shared equally amongst the nodes or participants in the network. *Decentralised database where every participants/nodes have equal access to the database*
**Advantages**
1. Transparency
2. Security
3. Data is immutable
# Cryptocurrency
## Characteristics/Advantages of cryptocurrency
### Borderless transaction
- Transaction can be done quickly and efficiently
- It uses blockchain technology
	- Removes the need of any intermediaries
	- Removes the transaction fees
### Financial inclusion
- Improves financial inclusion where people who are underbanked or unbanked are provided financial services
- Allows conversion of currency easily through transaction of cryptocurrency
### Decentralised
- Uses decentralised system, blockchain technology, where the database is shared equally amongst the nodes/ participants
- There is no central of authority such as government or financial institution to dictate the value or the flow of cryptocurrency
## Disadvantages of cryptocurrency
### Illegal purchases
- Users can use cryptocurrency to purchases illegal items or substances from the deep web/ dark web
### Energy consumption
- The mining of cryptocurrency uses a lot of computational power or electrical input, resulting in high energy consumption
- It also generates a huge amount of heat
### Not refundable or cancellable
- Any transactions made are permanent and cannot be changed since it uses the block chain technology.
