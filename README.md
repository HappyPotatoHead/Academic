# How To Use

This repository is best viewed in [Obsidian](https://obsidian.md/).

Please install these plugins for the best experience:
1. Dataview
2. Excalidraw
3. Execute Code
4. Force note view mode
5. Sheets Extended

Load the custom css file to load the custom callouts.
